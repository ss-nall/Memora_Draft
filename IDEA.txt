2. Project Name

Memora

Project Description

Memora is an AI-powered event memory platform.

After an event, photographers upload thousands of photos and videos.

Users join an event through a QR code or invite link.

Users register their face once.

The AI automatically identifies users inside uploaded photos and videos.

Each user receives:

• Personalized Gallery

• Video Moments

• AI Memory Reel

Users can download or share their memories.

If a real video exists, the application returns a trimmed clip.

If no video exists, the application automatically generates an AI Memory Reel from photos.

The system should support thousands of users and multiple simultaneous events.

The project must be modular, scalable and production-ready.

The application should use responsive web design.
