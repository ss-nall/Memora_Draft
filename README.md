# Memora

Memora is a production-quality AI-powered event memory platform.

## Description
After an event, photographers upload photos and videos. Users join an event through a QR code or invite link. The AI automatically identifies users inside uploaded photos and videos.

Each user receives:
- Personalized Gallery
- Video Moments
- AI Memory Reel

## Technology Stack
- **Frontend**: Next.js, TypeScript, Tailwind CSS, Shadcn UI
- **Backend**: Python, FastAPI, SQLAlchemy, PostgreSQL (Supabase)
- **AI Processing**: InsightFace, OpenCV, FAISS
- **Media Storage**: Cloudinary

## Structure
- `frontend`: Frontend Next.js application
- `backend`: Backend FastAPI services
